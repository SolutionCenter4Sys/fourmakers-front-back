# Versoes DataForge — Reembolso

Esta pasta armazena os arquivos versionados de massa de dados da demo:

- `reembolso.data.v1.js`
- `reembolso.data.v2.js`
- ...
- `reembolso.data.v10.js`

Regras:

- Nunca sobrescrever versao existente.
- Manter no maximo 10 versoes.
- Ao atingir `v10`, limpar versoes anteriores e reiniciar em `v1`.
